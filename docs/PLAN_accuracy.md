# gTAO-Net — correction plan (v2, revised 2026-11-17 evening)

Goal: make the gTAO results robust enough that a reviewer, or a thesis jury, can no
longer say "the negative fusion result is a preprocessing failure". Also turn the
who-vs-when diagnosis into the "analyzing" part of the PhD subject.

PhD subject: *A multimodal system for recognizing and analyzing student attention in
the classroom.* Each phase below names the title word and hypothesis it serves.

Machines: the **numbers in the paper and thesis come from Kaggle** (public notebooks =
verifiable); the **M5** is for quick local checks; the **Windows PC** downloads and
extracts the full DIPSER (Phase 3).

## 0. What we know now (replaces the morning's assumptions)

| Evidence | Implication |
|---|---|
| **63% of the label variance is between students** (per-student medium share 0.00-1.00) | Attention labels in DIPSER behave mostly like a stable student trait |
| Every v2 model: 50-87% of its prediction variance is between students; **within-student r ≈ 0 to +0.07**, best model included (mesh+soft: between +0.42, within +0.03) | The models recognise **who** is attentive, not **when** |
| Face/CORAL -0.163 = between-student r of -0.2 to -0.33, within r +0.03. **Person-bootstrap CI [-0.298, -0.018] excludes 0** (corrected 2026-11-17: it is NOT just noise) | A consistent reversed ranking of students. Likely a known artefact of grouped CV when labels are person-level traits: with ~16 training persons, train and test label shares are anti-correlated (r = -1.00). The window-permuted control cannot reveal this, because it destroys the person-level label structure |
| Effective sample size = **~20 persons**, not 1,566 windows | Pooled QWK is a 20-point ranking statistic: very noisy. More **persons** is what helps |
| Inputs were never standardised | Still a fair reviewer objection; v3 tests it |
| Paper I's face score 0.517 (and thesis H1: 0.034 -> 0.127) used session folds on 40 sessions | **Unknown whether they are also mostly between-student.** Check before resubmitting Paper I or finalising H1 |

## Rules that keep this honest

- Keep nested epoch selection, 3 seeds and the permuted control. Every table is
  regenerated by script.
- **Person-grouped, stratified folds** from v3 on (the same student never on both sides).
- Success criteria are written **before** results are seen. Every phase is reported,
  including the failures.
- v2 results stay frozen; new runs go to new folders.
- **Holm correction** across the factorial contrasts. **Person-level bootstrap CIs**
  (resample persons, not windows) on every headline QWK.
- The who-vs-when analysis is **post hoc**. It goes in the paper and thesis as
  *exploratory*, never as a new hypothesis.
- Whenever a gTAO number changes, update the paper, thesis ch-fusion and the
  H4/H5 rows of the thesis verdict table **together**.

## Phase 3b — Combined-fixes run on the full corpus: PRE-DECLARED criteria

**Written 2026-11-18 23:30 (Mac), before any model has been run on the full corpus.**

### Data and protocol (fixed)

- `corpus_full.npz`: 57 persons, 483 sessions, 35,649 windows of 4 s, low/med/high =
  12306 / 17964 / 5379 (high 15.1%). Verified on the Mac against `results/phase3/`.
- **3-class task** (3,930 complete high windows). No binary fallback.
- Folds: **person-grouped, label-stratified 5-fold** (a person never on both sides),
  **training-fold z-score** (v3 `fold`), nested epoch selection, 3 seeds, the same
  33-config grid as v3. Primary population: windows where the stream is available;
  fusion uses complete windows, plus the mask-aware variant if Phase 2 is built in time.
- Every headline number: QWK, balanced accuracy, high-class recall, with a
  **person-level bootstrap 95% CI** (resample persons, 2,000 draws).

### Label-only facts known before the run (computed 2026-11-18, no model involved)

Share of label variance: person 0.13 · group-experiment 0.20 · session 0.49. Mean
within-session label s.d. 0.443; 17/483 sessions have a constant label.
**Experiment prior:** predicting each window from the mean label of the *other* persons
in the same group/experiment (no input features at all) gives **QWK 0.372, r 0.41**
(leave-person-out; script `analysis_v3/label_prior.py`).
Consequence: under person-grouped folds, a model that only recognises *which
experiment* a window comes from can beat every v3 score. A high QWK is therefore not
evidence of attention recognition by itself. Criteria (b) and (c) exist for this reason.

### Reference rows (computed in the same run)

- R0 window-permuted control (as before).
- R1 **person-shuffle control**: each person receives another person's label sequence
  (folds unchanged). Fix 6, now required, not optional.
- R2 the experiment prior above, recomputed on the run's own outer folds.

### The fixes as factors

| # | Fix | Levels | Built from |
|---|---|---|---|
| 1 | v3 protocol | fixed (above) | existing features |
| 2 | Physiology context length | 4 s (as now) / 16 s / 32 s trailing window ending at the label window's end | **PC re-extraction, physio only** (watch CSVs) |
| 3 | Temporal context | k = 0 / 2 / 4 previous windows (causal, same session, contiguous only), mean + last | existing features (`keys` = session#t_start) |
| 4 | Rater lag | features of window t-l with label t, l = 0 / 1 / 2 windows (0 / 4 / 8 s) | existing features |
| 5 | Per-person calibration | off / per-person feature z-score over all that person's sessions, **features only, never labels** | existing features |

Fix 2 is the only one that needs the raw data. True 16/32 s Tchebichef moments cannot
be built from 4 s coefficients. Fix 3 covers concatenated short windows.

**Selection is nested:** the levels of fixes 2-5 are chosen per outer fold on the
inner validation split, never on the outer test fold. The full factor grid is reported
descriptively. Each fix is also reported as a contrast: chosen level vs off, paired over
configs and seeds, **Holm across the 4 fix contrasts**.

### Gate 3 (the success criteria)

- **(a) Recovery:** at least 2 of {face, head pose, physiology} reach QWK >= 0.10
  with person-bootstrap CI lower bound > 0, **and** above R1 by a CI that excludes 0.
- **(b) State signal:** at least one stream has **within-session r >= 0.10** (prediction
  and label both centred on their session mean; person-bootstrap CI lower bound > 0).
  Within-person r (centred on the person mean) is reported beside it but does not count:
  across sessions it mixes in the experiment effect.
- **(c) Beyond the experiment:** for the best single stream and the best fusion, the
  partial correlation of prediction with label **controlling for R2** is >= 0.10 with
  CI lower bound > 0.
- **(d) Fusion verdict (H4):** count of fusions above the best single stream, Holm-
  corrected paired tests. **H4 flips** only if best fusion - best single > 0 with a
  person-bootstrap CI lower bound > 0 **and** p_holm < 0.05. Otherwise H4 stays rejected.
- **(e) Fix verdicts:** a fix "helps" only if its Holm-corrected contrast is < 0.05 and
  its ΔQWK CI excludes 0. Its effect on within-session r is reported in the same row.

**Reading the outcome (decided now):**
- (a)+(b)+(c) pass: attention is recognisable beyond who and which experiment. Paper
  moves to the full corpus as primary data.
- (a) passes, (b) or (c) fails: the models recognise context (person / experiment), not
  attention state. Reported as such; the who/when analysis becomes "who / which
  activity / when".
- (a) fails on 57 persons: the negative result is **not** a sample-size artefact. That
  strengthens the paper's negative claims; Phase 5 (GPU face encoder) is the last
  remaining lever.

### Amendment 1 (2026-11-18 23:50, Mac): implementation, before any real result

Seen when this was written: label-only statistics, plus **smoke-test outputs on 6
persons / 8 epochs (`GRID_FAST`) used only to check the code**. No full-corpus model
result exists. Kernel: `kaggle/v3b_fullcorpus/dipser_grid/gtao_grid.py`; analysis:
`analysis_v3/gate3.py` (criteria applied mechanically).

- **Compute:** one Kaggle kernel per seed (3 kernels). Each runs: level selection, the
  33 configs + 5 classmate controls, 5 ablation arms on the 8 single-stream configs, and
  6 leave-experiment-out configs. Estimated 5-6 h on a T4 per seed (superseded by Amendment 2).
- **Selection** is coordinate-wise, not a full factorial (compute): unimodal CORAL probe
  per stream, same inner person split for every level, order physio length -> lag ->
  context -> calibration; a non-base level is adopted only if it beats the current
  inner QWK by > 0.01. The "full factor grid" of Phase 3b is replaced by the selection
  trials (logged per fold in `selection_seed<k>.json`).
- **Population:** complete windows whose 2 preceding windows exist and are complete
  (so every lag level scores the same rows). Context uses edge padding at gaps.
  Where the 16/32 s physio context is unavailable, the 4 s vector is used.
- **R1 is the classmate control:** each session gets a classmate's labels at the same
  4 s moment of the same class (sessions of one experiment share the clock, checked).
  This keeps person-independent class/experiment/moment structure and removes only the
  individual: stricter than the whole-person shuffle. Label-only: the class-moment
  prior gives QWK 0.378 (experiment prior 0.372).
- **(c)** passes on the best single stream; the best fusion's partial r is reported
  beside it. **(d)** p is the two-sided person-bootstrap p of the difference (a family
  of one). **(e)** contrasts use the ablation arms (one fix reverted at a time) on the 8
  single-stream configs: Wilcoxon over config x seed pairs, Holm across the 4 fixes;
  "helps" also needs a positive mean difference. The `base` arm (all fixes off = v3
  protocol on the full corpus) is reported descriptively. A fix never selected in any
  fold is reported as "never selected" with p = 1.
- **Calibration (fix 5) is transductive:** it uses a test person's own unlabelled
  features (never labels). Declared as such.
- Within-person r is reported beside within-session r (descriptive).

## Phase 8: time context (pre-declared 2026-11-20, before any result)

Motivation: Phase 6/7 exhausted the per-window features. Labels persist (80% of windows
share the previous window's label; sessions <= 74 windows of 4 s) and 49% of label
variance is between student-sessions, which a window-by-window model cannot use.

Setup (`kaggle/v8_context/context.py`): corpus_rich + corpus_crop, complete windows (all
streams, same population as v4/v6), fixed orders declared now: face 8x8, face crop
(Tchebichef) 8x8, temporal 5 for every stream, physio as stored. Same 5 person-grouped folds
as the v4/v6 cv5 (StratifiedGroupKFold(5, shuffle, seed 0)), 3 seeds. Epochs chosen on an
inner 20% person split of the training fold (nested; the scored fold never trains or selects).
Arms (identical towers / hyper-parameters, fixed in advance, no search):
  none  : window-only model (no context)
  ema   : causal exponential smoothing of `none` probabilities within the session
          (alpha picked on the inner split from {0, .5, .7, .8, .9, .95})
  gru   : causal GRU over the student's previous windows in the session (past only:
          deployable live); time gap between windows is an input
  bigru : bidirectional GRU (offline analysis only; EXPLORATORY)

## Phase 9: class context (pre-declared 2026-11-21, before any result)

Question: do the classmates' SENSOR features at the same moment help predict a student's
attention? (Labels of classmates are never an input.) Class moment = group/experiment +
4 s slot round((t - first window of the class session) / 4), the rule of the label-only
class-moment prior (QWK 0.378). Class features = mean of the other students' features in
the same class moment (complete windows), per stream, plus the number of classmates.

Protocol: **leave-one-class-out** (3 folds = group_01 / 02 / 03; 20 / 21 / 16 persons).
Reason: with person-grouped folds, a test student's classmates are in training with their
labels, so class features would let the model look up the classmates' labels at that
moment (a label prior in disguise, impossible for a new class). Under leave-one-class-out no
label of the test class is ever seen. Epochs: inner leave-one-group-out on the 2 training
groups (mean best epoch), then retrain on both with that count. 3 seeds. Same streams and
orders as Phase 8 (face 8x8, crop 8x8, temporal 5, physio as stored), window-only MLP.
Arms: own (student's features), own_class (+ class features), class_only (exploratory).

Decision rule (QWK primary): own_class vs own, paired person bootstrap of pooled
out-of-fold QWK (57 persons, 2000 draws, seeds averaged): class context "helps" if the 95%
CI excludes 0 and p < 0.05.
Exploratory (not confirmatory): class_only; and own vs own_class under person-grouped
5-fold (1 seed) to measure how much the leak-prone protocol would inflate the gain.

### Phase 9 RESULT (2026-11-22, `analysis_v3/phase9.py`, `results/v10/`)

Leave-one-class-out, 57 persons, 3 seeds (28,926 windows, majority 54.4%):
own 53.9% / QWK 0.085; own_class 55.2% / 0.103; class_only 49.5% / 0.126.
Confirmatory: own_class vs own QWK +0.019 [-0.015, +0.052], p 0.27 -> **class context
does NOT help** under the pre-declared rule (accuracy +1.4 points [+0.1, +2.7], secondary).
Exploratory:
- leak-prone person-grouped 5-fold: own_class vs own +0.143 [+0.080, +0.204], p < 0.001
  (QWK 0.173 -> 0.316): with classmates' labels in training, class features act as a label
  lookup. This "gain" is not available for a new class.
- own features, person-grouped vs leave-one-class-out (seed 0): QWK 0.173 -> 0.070,
  -0.103 [-0.170, -0.038], p < 0.001: person-grouped evaluation is itself optimistic;
  part of what models learn is specific to the class sessions seen in training.
Reading: on a class never seen in training, every sensor model is at QWK ~0.07-0.13.

## Phase 10A: sparse-probe tracking (pre-declared 2026-11-23, before any model result)

Task: in each student-session (windows in time order, index i), the hard label of every
window with i % P == 0 is known to the model (a "probe"). The model predicts the other
windows causally: it may use the sensors of the current window, the sensors of the last
probe window, the labels of the last two probes and the time since the last probe. Never
a label after the window, never another student's label. P in {8, 15, 38} windows
(32 s, 1 min, 2.5 min). All 35,649 windows (missing streams = missing values).
Caveat fixed now: the probe is the consensus label (4 external raters + self), an
optimistic stand-in for a self-report probe; per-rater labels are not in the corpus.

Protocol: leave-one-class-out (3 folds = group_01 / 02 / 03), 3 seeds, pooled
out-of-fold, scored on non-probe windows only. Model: gradient-boosted trees
(sklearn HistGradientBoosting, fixed settings: 300 iterations max, learning rate 0.05,
early stopping on 15% of the TRAINING persons); face and face-mesh reduced by PCA
(32 components each, fit on training folds). No tuning on the test folds.

Arms: persist (last probe label, no model); label_only (model on probe labels + time
since probe, no sensor); full (label_only inputs + current sensors + sensor difference
to the last probe window); sensors_only (no probe, reference).

Decision rules (QWK primary, paired person bootstrap, 57 persons, 2000 draws, seeds averaged):
1. **Sensors help tracking** if full vs label_only has a 95% CI excluding 0 and Holm-adjusted
   p < 0.05 over the three P.
2. **Target reached** at a given P if the best deployable arm (label_only or full) has
   accuracy >= 70% and QWK >= 0.50 on the held-out class. Which arm reaches it is reported:
   if only the probe does the work, the claim is "sparse probes suffice", not "sensors read
   attention".
3. full vs persist is reported, not a gate.
